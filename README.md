## 1. Core Capabilities (3D, Blender, CAD, Interactive Draw, Games & Open-Source Canva Decks)
- `threejs_webgl_webgpu_3d_scene_generator`: Procedural Three.js scenes with orbital cameras and ControlNet Depth/Normal/Wireframe passes.
- `blender_bpy_and_parametric_cad_stl_compiler`: Generates Blender `bpy` Python automation scripts and watertight manifold ASCII `.STL` parametric CAD enclosures (e.g., `CitySocket™` and `CaptureNode™` IP65 housings).
- `interactive_2d_3d_vector_canvas_draw_engine`: SVG & HTML5 Canvas interactive sketching and Excalidraw/TLDraw-style node-graph boards.
- `playable_wasd_3d_game_and_manim_explainer_studio`: Playable WASD 3D physics game loops (Three.js / Godot 4) and Manim 3Blue1Brown mathematical animations.
- `open_source_canva_brand_svg_and_slidev_marp_deck` (`GET /api/design/brand-deck`): 100% free & open-source **Canva** replacement generating parameterized `1200x630` vector SVG brand banners (`Graphite.rs` / `Inkscape`) and Markdown **Slidev / Marp** presentation decks.
