# 🏗️ `InsightDesign™` Architecture (`:4024 /api/design`)

## 1. Mission & 6 Open-Source Creative/Spatial Modes
`InsightDesign™` consolidates the 83 chapters of `Book_Lit_Master_blender_onshape_3d_cad.md`, `Book_Context_j9j_d7AGSDc.md` (*Alternative Design Tools: Graphite, Inkscape, Blender, Godot*), and `ChronicleRAG`'s code-first 3D generators into 6 deterministic modes:
1. `threejs_3d_scene`: Procedural Three.js scenes with orbit camera rigs and ControlNet passes.
2. `parametric_cad_stl`: Watertight manifold ASCII `.STL` enclosures with CAS SHA-256 pointers (`cas://sha256/...`).
3. `blender_bpy_script`: Automated Blender `bpy` Python mesh & bevel modifiers.
4. `interactive_draw_canvas`: Interactive 2D/3D SVG & HTML5 Canvas vector drawing boards.
5. `playable_3d_game`: Playable WASD 3D physics & collision game loops.
6. `brand_svg_and_slidev_deck`: 100% open-source **Canva** replacement outputting parameterized `Graphite.rs` / `Inkscape` SVG social banners and **Slidev / Marp** Markdown pitch decks.
