# 🏛️ `InsightDesign™` Wiki Home

Welcome to the official knowledge base for **`InsightDesign™`** (`:4024 /api/design`).

## Quick Links
- **Core Tier**: `insightCoreAI + insightCoreIO`
- **Primary Mandate**: 3D Three.js, Blender `bpy`, Parametric CAD (`.STL`/`.STEP`), Interactive Draw, Playable 3D Games & Open-Source Canva Brand/Slidev Deck Engine
- **Open-Source Endpoints**:
  - `GET /api/design/brand-deck` — Open-Source **Canva** Replacement (`1200x630` SVG Brand Card + **Slidev / Marp** Markdown Presentation Deck)
  - `GET /api/design/modes` — Lists all 6 supported modes (`threejs_3d_scene`, `parametric_cad_stl`, `blender_bpy_script`, `interactive_draw_canvas`, `playable_3d_game`, `brand_svg_and_slidev_deck`)
  - `POST /api/design/execute` — Full 3D / CAD / Blender / Game / Brand Deck generation
